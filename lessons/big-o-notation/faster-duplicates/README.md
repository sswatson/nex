# Faster duplicates

`duplicates.py` contains the $O(n^2)$ `has_duplicate` from the lesson.
Rewrite it to run in O(n).

Check your work with:

```sh
python3 test_duplicates.py
```

The tests check correctness first, then run the function on a large input —
the quadratic version blows the time budget, a linear version passes easily.
